# Theta PM SEO Roadmap — Week of 2026-08-10

Source of truth for this week's SEO publishing. 120 pages total, organized into 10 topic clusters.

## Product truth (what we can honestly claim)

Theta PM v1.0.0 is a project management platform with:

- Workspaces & projects, project overviews
- Task management with custom fields, task dialog, activity feed
- Kanban boards, Timeline (milestones), Gantt, Calendar views
- Team collaboration, mentions, inbox/notifications, direct messages
- Automation and workflow rules
- Integrations: GitHub (repos, issues, PRs), Bitbucket, Asana, Trello, Slack, Figma, Canva, WooCommerce
- Portfolio view, dashboard analytics, real-time updates (Ably)
- Auth via Clerk, billing/subscriptions

Never claim features not visible in the UI. Never mention Nova (removed). Product name is **Theta PM**.

## Anti-cannibalization guardrails

- Each primary keyword assigned exactly once (see tables above).
- Comparison pages use "theta vs X"; alternatives use "X alternative"; never both for the same competitor.
- Feature pages target "software" keyword forms; guides target "how to"; never overlap.
- Review keyword assignments before any new page is added to the roadmap.

## Internal linking map

- Every feature page links to its cluster pillar + related features.
- Every comparison page links to the pillar `#1`, the alternatives counterpart, and a feature page.
- Every guide links to 2+ feature pages and 2 sibling guides.
- Every solution page links to a feature page and a comparison page.
- All pages link to `/pricing` and `/sign-up` CTAs.
